# ADR 0003: Native Blended List Ads

## Status
Accepted

## Context
Persistent bottom banner ads intruded on document viewport controls and caused visual distraction.

## Decision
Replace bottom banner ads with native styled cards inside recent files feeds and tool collections with a clean [ Ad ] badge.

## Consequences
- Clean, non-intrusive UI matching the modern minimalist aesthetic.
- Zero layout shifting or control obscuration.
